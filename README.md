## 🌳 𝐅𝐨𝐫𝐞𝐬𝐭𝐒𝐑𝐃 / 𝐅𝐨𝐫𝐞𝐬𝐭𝐈𝐃 — 𝐏𝐫𝐨𝐲𝐞𝐜𝐭𝐨 𝐏𝐫𝐢𝐧𝐜𝐢𝐩𝐚𝐥

> Sistema de registro georreferenciado de árboles mediante códigos QR, desarrollado para apoyar el cumplimiento de la normativa ambiental colombiana (Ley 2173 de 2021) en compensaciones forestales corporativas.

| Característica | Descripción |
|---|---|
| 📍 Geolocalización | Cada árbol registrado con un código QR único y coordenadas GPS |
| 🗄️ Base de datos | Esquema relacional de 8 tablas, basado en UUID, MySQL |
| ⚖️ Cumplimiento normativo | Alineado con la Ley 2173 de 2021 (compensación forestal en Colombia) |
| 👥 Equipo | Desarrollado junto a Gabriel Jaime Correa Correa y Valentina Hernández Zapata |
