## 🌳 𝐅𝐨𝐫𝐞𝐬𝐭𝐒𝐑𝐃 / 𝐅𝐨𝐫𝐞𝐬𝐭𝐈𝐃 — 𝐌𝐚𝐢𝐧 𝐏𝐫𝐨𝐣𝐞𝐜𝐭

> Georeferenced tree registration system using QR codes, built to support compliance with Colombian environmental law (Ley 2173 de 2021) for corporate forest compensation programs.

| Feature | Description |
|---|---|
| 📍 Geolocation | Each tree registered with a unique QR code and GPS coordinates |
| 🗄️ Database | 8-table relational schema, UUID-based, MySQL |
| ⚖️ Compliance | Aligned with Ley 2173 de 2021 (Colombian forest compensation law) |
| 👥 Team | Built with Gabriel Jaime Correa Correa and Valentina Hernández Zapata |
